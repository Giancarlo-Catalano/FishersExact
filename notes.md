# Links
 * https://pypi.org/project/fisher-rxc/
   * Python package that does exact r x c tests, but also approximations for larger tables.
     * Exact uses Mehta & Patel's Network Algorithm
     * Monte Carlo simulation for approximation 
 * https://people.sc.fsu.edu/~jburkardt/c_src/asa159/asa159.html
   * This algorithm generates random tables with the correct margins
 * https://www.langsrud.com/fisher.htm
   * this page calculates the p-value for 2 x 2 tables in JavaScript
 * https://docs.rs/fishers_exact/latest/fishers_exact/
   * Rust crate that calculates fishers exact for 2x2 tables 
 * https://github.com/dnafinder/myfisher
   * Code for fishers test for some table sizes, in MATLAB
